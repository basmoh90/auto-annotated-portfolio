# Auto Tag Interlink - Quick Start Guide

## 🚀 Get Started in 3 Minutes

### Step 1: Install & Activate

1. Upload `auto-tag-interlink` folder to `/wp-content/plugins/`
2. Activate via **Plugins** menu
3. Go to **Settings → Auto Tag Interlink**

### Step 2: Configure Basic Settings

**Recommended for beginners:**
- ✅ Enable Auto-Linking: ON
- ✅ Link in Headings: OFF (safer)
- ✅ Post Types: Select `Post`
- ✅ Max Related Posts: 10

Click **Save Changes**

### Step 3: Test It!

**Create Test Posts:**

**Post 1: "WordPress Tips"**
- Tags: `WordPress`, `Tips`
- Content: "Here are some WordPress tips for beginners..."

**Post 2: "Advanced WordPress"**
- Tags: `WordPress`, `Advanced`
- Content: "This guide covers advanced WordPress techniques..."

**Post 3: "Best Tips for Bloggers"**
- Tags: `Tips`, `Blogging`
- Content: "Follow these tips to improve your blog..."

**Save Post 1 again** → Check the content → You'll see automatic links!

## ⚙️ Advanced: Using Keywords

Add custom field to your post:
- **Field name:** `keywords`
- **Value:** `SEO, performance, speed`

These keywords work like tags for linking!

---

## 🔧 Troubleshooting Quick Fixes

**No links appearing?**
→ Check Settings → ensure plugin is enabled  
→ Verify posts have matching tags  
→ Clear cache and re-save post

**Too many links?**
→ Reduce "Max Related Posts" to 5

**Performance slow?**
→ Click "Clear Cache" button  
→ Reduce max related posts
